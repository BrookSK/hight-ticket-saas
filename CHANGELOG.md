# Changelog

Histórico de novidades da plataforma, escrito para o usuário final.
O projeto segue versionamento semântico (MAJOR.MINOR.PATCH).

## [0.1.0] - 2026-09-07

- Primeira versão da fundação da plataforma.
- Nova área de acesso com tela de login e painel administrativo.
- Página institucional inicial de apresentação do produto.
- Perfis de acesso e permissões prontos para controlar quem vê e faz o quê.
- Central de Configurações Gerais preparada (sem depender de arquivos técnicos).
- Suporte a idiomas, começando pelo Português do Brasil.
- Experiência visual moderna, responsiva e pronta para uso no celular.
